# Mo-Sys demo project

Unity project to try out Cluster Display with a Mo-Sys camera tracking device.

See the [documentation](../../source/com.unity.cluster-display/Documentation~/sample-projects-mosys.md) for more details.

> **Not maintained.** This project is still on Unity 2022.2 (beta), its manifest points to a package folder that no longer exists (`MissionControl/com.unity.cluster-display.mission-control`, Mission Control is now part of `com.unity.cluster-display`) and it depends on the third-party package `com.unity.live-capture.mosys`. It has not been migrated to Unity 6. The documentation and the `f4-simulator` folder are kept as reference for integrating a Live Capture device with a cluster.
